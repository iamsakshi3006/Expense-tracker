# SpendWise – Expense Tracker

## About the Project
SpendWise is a responsive expense tracking web application built using HTML, CSS, and JavaScript. It helps users manage their daily expenses, monitor monthly spending, and maintain a budget.

## Features
- **Add Expenses:** Record expenses with a title, amount, category, date, and optional description.
- **View Expenses:** Display all transactions dynamically.
- **Edit and Delete:** Update existing expenses or delete them after confirmation.
- **Expense Summary:** View total spending, monthly spending, and transaction count.
- **Monthly Budget:** Set a monthly budget and see the remaining balance or budget warning.
- **Filter and Sort:** Filter expenses by category and month, and sort them by date or amount.
- **Dark and Light Mode:** Switch themes and remember the selected preference.
- **Local Storage:** Save expenses and budget data in the browser so they remain available after refreshing the page.
- **JSON Import and Export:** Download a JSON backup of expense data and import it later.
- **Responsive Design:** Use the application on desktop, tablet, and mobile screens.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Browser Local Storage
- JSON

## How to Run the Project
1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the Live Server extension.
4. Start adding and managing expenses.

## Data Storage
The application stores expenses, budget details, and theme preferences in the browser's Local Storage. Clearing browser storage may remove saved data, so users can export a JSON backup to preserve their expenses.
